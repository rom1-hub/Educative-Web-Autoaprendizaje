# Coq v0.8 — corrección de feedback de conjugación

Se corrigió la versión anterior para que los cambios sean efectivos:
- Eliminado el contador «1 bonne(s), 2 bonne(s)…» del encabezado y de la lógica visual.
- El primer error queda registrado y, si el alumno se autocorrige, el resumen lo muestra como «Primer error · corregida solo».
- Si falla dos veces, la segunda respuesta queda registrada como error y la solución mostrada se resalta visualmente, con fondo, negrita y subrayado.
- El alumno debe escribir la solución y validarla antes de continuar.
- El resumen final distingue las tres situaciones: correcta al primer intento, corregida por el alumno tras el primer error, o corregida con ayuda tras dos errores.
