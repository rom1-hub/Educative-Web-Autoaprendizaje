02 · Información importante

Aspectos que debes recordar

El sujeto es obligatorio

En francés, el uso de un sujeto es imprescindible.

No se puede decir o escribir «suis»: es obligatorio poner «je suis». Y esto ocurre con todos los verbos.

Los dos usos de «on»

El pronombre «on» representa dos contextos diferentes:

  • Sinónimo de «nous»: on est = nous sommes = somos / estamos.
  • Uso impersonal o generalización: on doit manger pour vivre = se debe comer para vivir / debemos comer para vivir.

Las tres traducciones de «vous»

El pronombre «vous» se traduce de tres maneras diferentes en español:

  • vous êtes = vosotros/as sois / estáis.
  • vous êtes = usted es / está.
  • vous êtes = ustedes son / están.
