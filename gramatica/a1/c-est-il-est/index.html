Gramática · A1 · Lección 16

Diferencia entre C’EST y IL EST

En español, «es» y «está» pueden traducirse de distintas maneras al francés. Aprende cuándo utilizar C’EST y cuándo utilizar IL EST.

Nivel A1Identificar · Presentar · Describir · La hora
01 · Introducción

¿Por qué se confunden?

En español solemos omitir el sujeto: decimos «es mi amigo», «es simpática» o «son las ocho». En francés, en cambio, normalmente necesitamos expresar un sujeto.

Por eso, una misma forma española puede corresponder a estructuras francesas diferentes:

C’EST / CE SONTIL EST / ELLE EST / ILS SONT / ELLES SONTLa elección depende de lo que queremos identificar, presentar o describir.
02 · C’EST / CE SONT

Primera categoría: identificar o presentar

Utilizamos C’EST en singular y CE SONT en plural para identificar o presentar una persona o una cosa.

C’EST + déterminant + nomCE SONT + déterminant + nom au plurielC’est / ce sont + determinante + sustantivo
FrancésEspañol
C’est mon ami.Es mi amigo.
C’est une artiste connue.Es una artista conocida.
Ce sont des personnes sympathiques.Son personas simpáticas.

También delante de un nombre propio

FrancésEspañol
C’est Julia.Es Julia.
C’est Romain.Es Romain.
Ce sont Ana et Mary.Son Ana y Mary.
03 · C’EST / CE SONT

Segunda categoría: presentar o identificar a alguien

Para identificar a una persona, también utilizamos C’EST o CE SONT seguidos de un pronombre tónico.

C’EST + pronom toniqueCE SONT + pronom tonique au pluriel
FrancésEspañol
C’est moi !¡Soy yo!
Qui c’est ? C’est nous !¿Quién es? ¡Somos nosotros!
Ce sont eux qui ont commencé.Son ellos los que empezaron.

En estos ejemplos, moi, nous y eux son pronombres tónicos, no pronombres sujeto.

04 · C’EST

Tercera categoría: indicar una fecha o un momento

Utilizamos C’EST para indicar o identificar un día, una fecha, un año o un momento.

FrancésEspañol
C’est quel jour, le concert ? C’est vendredi.¿Qué día es el concierto? Es el viernes.
C’est le 25 mai.Es el 25 de mayo.
C’est en 2024.Es en 2024.
C’est ce week-end.Es este fin de semana.

Para indicar la hora exacta, normalmente utilizamos IL EST. Veremos esta estructura en la sección correspondiente.

05 · C’EST

Cuarta categoría: precisar un lugar

Podemos utilizar C’EST para señalar o situar algo o a alguien.

C’EST + adverbe de lieuC’EST + préposition + lieu
FrancésEspañol
C’est ici.Es aquí.
C’est à Marseille.Es en Marsella.
C’est en Argentine.Es en Argentina.
06 · C’EST

Quinta categoría: dar una opinión o hacer un comentario

También utilizamos C’EST para hacer un comentario general o expresar una valoración sobre una situación, una actividad o algo que acabamos de mencionar.

C’EST + adjectif masculin singulierC’EST + adverbe
FrancésEspañol
C’est bon !¡Está rico! / ¡Es bueno!
C’est amusant !¡Es divertido!
C’est intéressant.Es interesante.

Cuando C’EST introduce una valoración general, el adjetivo aparece normalmente en masculino singular, incluso si el elemento al que se refiere es femenino o plural.

07 · Una ayuda para elegir

¿Cómo distinguir C’EST de IL EST?

Una forma útil de orientarte es observar qué viene después de la expresión.

  • Si identificas o presentas a alguien o algo con un sustantivo, utiliza normalmente C’EST / CE SONT.
  • Si describes directamente a una persona o cosa mediante un adjetivo, utiliza IL EST / ELLE EST / ILS SONT / ELLES SONT.
IdentificarDescribir
C’est mon ami.Il est sympathique.
Es mi amigo.Es simpático.
C’est une artiste.Elle est connue.
Es una artista.Es conocida.

En español, puedes añadir «él», «ella», «ellos» o «ellas» para hacer explícito el sujeto: «él es simpático» → il est sympathique. Sin embargo, no debes traducir automáticamente todas las frases que empiezan por «es» con il est.

08 · Pronombres

Los pronombres tónicos

Los pronombres tónicos permiten destacar o identificar a una persona. También se utilizan después de determinadas preposiciones y en otras construcciones.

Pronombre tónicoTraducción orientativaPronombre sujeto
MoiYo / a míJe
ToiTú / a tiTu
LuiÉl / a élIl
ElleElla / a ellaElle
NousNosotros / a nosotrosNous
VousVosotros, usted, ustedesVous
EuxEllos / a ellosIls
EllesEllas / a ellasElles

Ejemplos para destacar a una persona

FrancésEspañol
Toi, tu es grand ; moi, je suis petit.Tú eres alto; yo soy bajo.
Eux, là-bas, ils parlent fort.Ellos, los de allí, hablan fuerte.

Observa que el pronombre tónico puede aparecer al principio para destacar a la persona y que después se mantiene el pronombre sujeto correspondiente.

09 · IL EST / ELLE EST

Primera categoría: caracterizar o describir

Utilizamos IL EST, ELLE EST, ILS SONT y ELLES SONT para describir o caracterizar directamente a una persona o cosa.

IL / ELLE EST + adjectifILS / ELLES SONT + adjectif
FrancésEspañol
Il est grand.Es grande / Él es grande.
Elle est belle.Es hermosa / Ella es hermosa.
Ils sont riches.Son ricos / Ellos son ricos.
Elles sont sympathiques.Son simpáticas / Ellas son simpáticas.

Nacionalidades, religiones y profesiones

Con nacionalidades y religiones expresadas mediante adjetivos, y con profesiones sin determinante, se utiliza también être directamente:

FrancésEspañol
Il est français.Es francés.
Elle est catholique.Es católica.
Elles sont professeures.Son profesoras.
10 · IL EST

Segunda categoría: indicar la hora

Para decir la hora en francés utilizamos la expresión impersonal IL EST.

IL EST + heure
FrancésEspañol
Il est midi.Es mediodía.
Il est 10 h 20.Son las 10:20.
Il est 18 h.Son las 18:00 / Son las 6 de la tarde.

Recuerda que en francés se utiliza il en esta expresión aunque no estemos hablando de un hombre o de una persona concreta.

11 · Comparación

Compara las dos estructuras

Con C’ESTCon IL EST / ELLE EST
C’est un professeur.Il est professeur.
Es un profesor.Es profesor.
C’est une femme intelligente.Elle est intelligente.
Es una mujer inteligente.Es inteligente.
C’est une maison magnifique.Elle est magnifique.
Es una casa magnífica.Es magnífica.

La primera estructura identifica o presenta mediante un sustantivo. La segunda retoma a una persona o cosa ya identificada y la describe directamente.

Una distinción que conviene recordar

Las dos estructuras pueden referirse a la misma persona o cosa, pero no se construyen igual. Compara:

C’est un médecin. (Es médico / Es un médico.)

Il est médecin. (Es médico.)

Con C’EST, el sustantivo suele ir acompañado de un determinante; con IL EST, la profesión se utiliza normalmente sin artículo.

12 · Síntesis

Resumen: ¿cuándo utilizamos cada forma?

C’EST / CE SONT
  • Identificar o presentar.
  • Delante de un sustantivo con determinante.
  • Con nombres propios.
  • Con pronombres tónicos.
  • Para fechas, momentos, lugares y comentarios generales.
IL EST / ELLE EST / ILS SONT / ELLES SONT
  • Describir o caracterizar directamente.
  • Delante de un adjetivo que describe al sujeto.
  • Con profesiones sin artículo.
  • Para indicar la hora con la expresión impersonal il est.

No traduzcas «es» o «está» de forma automática. Primero identifica si estás presentando o identificando algo, describiendo a alguien o indicando la hora. Esa función te ayudará a elegir la estructura correcta.
